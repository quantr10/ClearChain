Part 2: which launcher icon?

The design system says to use Material's eco leaf and not redraw it. Each option shows the icon on a light and a dark wallpaper, Android 13's themed (monochrome) version, and the Android 12+ system splash it produces. That splash comes before the app's own gradient splash. It's a flat colour, because the system can't draw a gradient there. Today it's light grey with the robot, even in dark mode.

1

White leaf on the brand gradient (my pick)

It matches the splash and the sign-in header, so the icon you tap, the splash and Login read as one thing. It stays legible at small sizes and stands out among the mostly white and blue icons on a typical home screen. The system splash is flat brand teal with the leaf in its disc, the same picture the app splash opens with, so the hand-off barely shows.
