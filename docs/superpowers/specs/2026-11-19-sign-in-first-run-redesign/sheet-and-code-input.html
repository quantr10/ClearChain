Part 3: how should people enter the 6-digit code?

Two screens ask for the same code, and today they do it differently. Verify email uses a bare Material field with no label, so a screen reader announces only "edit box", and its text sizes are hard-coded. Forgot password uses a labelled ClearChain field. Whichever you pick, both screens will use it. Shown on Verify email with the code half typed.

A

Six boxes (my pick)

The code is the only thing on this screen, so it gets the space. The boxes show how many digits are left, and pasting a copied code fills all six at once. Under the boxes it's still a single text field, so a screen reader announces "Verification code, 6 digits, 3 entered" rather than six separate fields. The boxes grow with the font size. This is a new shared component, CodeInputField, which I'd also add to the design system.
